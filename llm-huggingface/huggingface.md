## 🤗 Hugging Face

Hugging Face is an open-source platform that makes it easy to build, use, and share machine learning models. It is like a repository for AI models. It offers thousands of pre-trained models that developers can use without training from scratch. This saves time, reduces cost, and makes advanced AI technology accessible to everyone.

Mainly it provies some open-source code for model architecture. Also with easy-to-use libraries such as Transformers and a large model hub, Hugging Face helps developers quickly integrate powerful AI capabilities like text generation, translation, summarization, sentiment analysis, and more into their applications.


- 🤗 Hub - It is like a repository but for AI models and datasets.
- 📊 Datasets - It is a tool to load and manage data
- 🤖 Transformers - It is a library of ready-to-use AI models
- ⚡ PEFT - Parameter-Efficient Fine-Tuning, It helps to fine-tune big models without changing all their parameters.
- 🪙 TRL - Transformer Reinforcement Learning, It used to train large language models using reinforcement learning.
- ⏭️ - Accelerate - Makes training fast & scalable
