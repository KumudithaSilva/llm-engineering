#  🗃️ Retrival Augmentation

## Auto-regressive LLM

- It predcit the `next word` in a sequence, one word at a time.
- It learn by `predicting next token given all previous tokens`.
- It use cases are `Text generation`.


## Auto-encoding LLM

- It understand and compress text by reconstructing missing parts.
- It learn by `taking input and tries to predcit the masked one`.
- It use cases are `Text understanding`.


## Tokens

- A token is a `text that the model reads`.
- Example: 
    - Sentence: "Ice is Cool"
    - After Tokenizing: ["Ice", "is", "Cool"]


## Vector

- It is a `list of numbers`, representing a coordinates in n-dimensional space.
- It has no inherent meaning it is only coordinates.
- Example: [0.2, -0.5, 1.3, 0.7]


## Embeddings

- It is a `vector generated by a model that encodes semantic meaning`.
- It represents concepts, words, sentences, or documents such that `similar meanings are closer` in the vector space.
- In the embedding space, `vectors with similar meanings are closer`.


## Vector Embeddings

- It is a `numerical representation of tokens in a high-dimensional space`.
- It used to `capture semantic relationship` between tokens.
- It allows the model to process tokens mathematically, with `similar words or concepts having similar embeddings`.
